# DeskKit 桌面工具箱 · 帮助

> 📄 本文件随程序一起发布（程序目录下 `Help.md`）。**用记事本直接编辑保存，重新打开帮助窗口即可生效**，无需重装程序。

DeskKit 常驻系统托盘（屏幕右下角），把几个高频小工具合在一起：

| 模块 | 一句话说明 |
|---|---|
| **ShotShelf 暂存架** | 剪贴板收纳架：截图、复制的图文自动暂存，随时回贴 |
| **MiniPix 截图** | 区域/全屏截图、屏幕贴图、标注马赛克、长截图、OCR 识文 |
| **CtrlG 快捷跳转** | `Ctrl+G` 把任意程序的「打开/另存为」对话框跳到资源管理器当前目录 |
| **QuickG 粘贴即存** | 资源管理器里把复制的内容直接粘贴成文件 |
| **网络传输** | 电脑、手机浏览器之间互发文字/图片/文件 |

**两分钟上手**：

1. 截个图——按 `F1` 框选，松手自动进入暂存架；
2. 找回它——鼠标靠近屏幕右边缘，暂存架滑出，点卡片上的复制按钮即可回贴；
3. 更多功能——右键点托盘图标或暂存架窗口，所有功能都在菜单里。

---

## 一、暂存架

主窗口平时贴边收纳（默认右侧，只留一条窄边），鼠标靠近滑出、离开滑回；也可以按 `F2` 随时唤出/收回。

**三个标签**

| 标签 | 收纳内容 | 切换 |
|---|---|---|
| 图 | 截图、复制的图片 | `Alt+1` |
| 文 | 复制的文字 | `Alt+2` |
| 设备 | 网络传输的设备与会话 | `Alt+3` |

**常用操作**

- **复制任何内容都会自动进暂存架**，无需手动添加；
- 点卡片 = 预览；卡片上的复制按钮 = 回贴到剪贴板；
- **图钉**（固定）：常用条目钉住，「清空」不会删掉它；
- 右键菜单 →「清空当前轨道」只清当前标签的内容，已固定的保留；
- 「窗口置顶」勾选后暂存架始终浮在最前。

**图片预览窗**支持：旋转、裁剪（裁剪结果自动存回暂存架）、OCR 识文、复制、另存为。

**数据安全**：开启「磁盘缓存」（设置 → 暂存）后，暂存内容重启不丢；「自动保存目录」会把每张截图/文字另存一份（按时间命名，永不自动删除），位置和开关都在设置里改。

## 二、截图与贴图

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 区域/窗口截图 | `F1`（可改） | 拖出选区；遮罩左上角可直接输入宽×高精确截取 |
| 全屏截到剪贴板 | `Ctrl+Shift+C` 或 `Ctrl+Alt+C` | 不进截图编辑，直接全屏入剪贴板 |
| 剪贴板内容贴图 | `Ctrl+Alt+V` | 把剪贴板图片钉在屏幕上 |
| 另一区域截图热键 | `Ctrl+Alt+A` | 与 F1 相同，键位不同（方便冲突时备用） |

**截图编辑工具条**：画笔、文字、箭头、马赛克，线宽三档、颜色可选，支持撤销/重做；选区内**双击 = 直接复制**，回车 = 确认。

**长截图**：截图时点长截图按钮，框选后滚动页面自动拼接（滚动节奏可在「设置 → 长截图」调整）。

**屏幕贴图**：钉在屏幕上的图片可缩放、调透明度、鼠标穿透（不挡底下操作）；右键贴图可改边框、阴影、置顶。

## 三、OCR 识文（本地离线）

截图工具条点 OCR 图标（或在预览窗里点 OCR），即可把图中文字识别出来。

- 引擎：RapidOCR PP-OCRv5，**完全本地运行**——不出网、无额度、无隐私顾虑；
- 识别结果一键复制，复制后自动进暂存架；
- 首次使用需加载模型（约 1~2 秒），之后复用。

## 四、快捷跳转（Ctrl+G）

Listary 风格的目录直达：在**任意程序**的「打开 / 另存为」文件对话框里按 `Ctrl+G`，对话框自动跳转到你最近在资源管理器浏览的文件夹。

**典型场景**：

1. 在资源管理器里浏览到目标文件夹（如 `D:\项目\截图`）；
2. 回到软件里点「打开文件」——对话框默认停在别的目录；
3. 按 `Ctrl+G`——对话框立即跳到该文件夹，不用一层层点进去。

- 支持传统对话框与 Win10/11 新式对话框（IFileDialog），Chrome / Edge 等浏览器内嵌的文件选择框同样有效；
- 前台不是文件对话框、或没有可用的资源管理器位置时，静默忽略不弹任何提示；
- 托盘/右键菜单的「快捷跳转」可整体开关（关闭后释放热键）；
- 此功能由 CtrlG 模块提供。

## 五、QuickG 粘贴即存

在资源管理器里**复制文件**后，到别处按 `Ctrl+V` 粘贴**文本**时，自动改为把文本存成文件。

典型场景：聊天窗口里复制一段表格文字 → 到资源管理器直接 `Ctrl+V` → 生成 `.csv`/`.txt` 文件，省去新建文件再粘贴的步骤。

## 六、网络传输（设备互联）

电脑、手机、平板之间互发文字、截图、文件。**无需配对码，填网址直连。**

**方式一：浏览器直连（零安装，推荐手机用）**

1. 电脑上打开 托盘菜单 → 传输设置（或在设置 → 传输里点「打开传输设置…」）；
2. 窗口顶部有**服务网址**（如 `192.168.1.5:80`），点一下即可复制；
3. 手机浏览器打开该网址，即可收发文件、图片、文字。

**方式二：DeskKit 互连（电脑对电脑）**

- 在对方的「传输设置」里复制服务网址 → 在本机「传输设置 → 连接到其它电脑的 DeskKit」填入 → 点「连接」；
- 连接后双方「设备」标签互见，**点设备卡打开聊天窗口**：可发文字、`Ctrl+V` 粘贴截图、📎 选文件，对方收到的内容自动进暂存架；
- 直接**拖文件到设备卡上** = 发送；
- 断网/重启后自动重连；「忘记服务器」可清除连接记录。

**跨网段（进阶）**：两端都装 [Tailscale](https://tailscale.com) 并登录同一账号后，用 `100.x.x.x` 地址连接，即使不在同一局域网（如手机热点、异地）也能传。

**端口与防火墙**：默认监听 80 端口（可在传输设置修改）；首次启动如弹出防火墙授权，点「允许」即可。

## 七、设置

主窗口右键 →「设置…」，共六页：

| 分页 | 能改什么 |
|---|---|
| 外观 | 图/文/设备标签颜色、窗口背景色、背景跟随标签、预览背景色（色块点击弹系统取色器，立即生效） |
| 贴边 | 贴边收起的边、收起后的窄边宽度等收放参数 |
| 暂存 | 自动保存目录、是否捕获剪贴板文字、文字条数上限、磁盘缓存开关（后两项重启生效） |
| 长截图 | 滚动步长与延时（步长小+延时长 = 慢而稳） |
| 快捷键 | 截图、暂存架唤出、三个标签切换的热键；点击输入框直接按组合键，Esc 取消 |
| 传输 | 网络传输入口（设备改名、端口、接收目录在传输设置窗内） |

**开机自启**：托盘/右键菜单勾选「开机自启」；若注册表被防护软件拦截，自动降级为启动文件夹快捷方式。

## 八、快捷键总表

| 快捷键 | 功能 | 可改 |
|---|---|---|
| `F1` | 区域/窗口截图 | ✅ 设置 → 快捷键 |
| `F2` | 唤出/收回暂存架 | ✅ |
| `Alt+1` / `Alt+2` / `Alt+3` | 切换 图/文/设备 标签 | ✅ |
| `Ctrl+Shift+C`、`Ctrl+Alt+C`、`Ctrl+Alt+A` | 截图（固定三键） | ❌ |
| `Ctrl+Alt+V` | 剪贴板内容贴图 | ❌ |
| `Ctrl+G` | 快捷跳转 | ❌（可整体开关） |

> 全局热键与其它软件冲突时：可改项去设置里换键；固定键里 `Ctrl+Shift+C` / `Ctrl+Alt+C` / `Ctrl+Alt+A` 三键等价，错开冲突即可。

## 九、常见问题

**Q：截图/识文后文件存到哪了？**
默认自动保存目录（右键 →「打开保存目录」直接打开，位置可在 设置 → 暂存 修改）。

**Q：重启后暂存的内容丢了？**
开启 设置 → 暂存 →「磁盘缓存」（重启生效）。

**Q：手机连不上电脑？**
① 确认手机和电脑在同一 Wi-Fi；② 电脑端防火墙弹窗点过「允许」；③ 用传输设置顶部显示的网址（含端口）访问；④ 跨网段场景用 Tailscale 的 `100.x` 地址。

**Q：按 Ctrl+G 没反应？**
托盘菜单检查「快捷跳转」是否被取消勾选；部分全屏游戏/管理员权限程序里全局热键会失效。

**Q：复制后暂存架没反应？**
个别剪贴板监控软件会占用剪贴板，程序已内置重试；持续失败看日志 `%LOCALAPPDATA%\DeskKit\log.txt`。另外检查 设置 → 暂存 →「捕获剪贴板文字」是否被关闭（关闭后只暂存图片）。

**Q：想彻底退出？**
右键 →「退出」（同时移除托盘图标）。
